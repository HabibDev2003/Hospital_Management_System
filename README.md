# Hospital_Management_System

# Hospital to make hospital operations more organized, efficient, and easier to manage by replacing manual record-keeping with a computerized solution.

## 2. Project Objectives

- Develop a computerized Hospital Management System.
- Manage hospital information in an organized way.
- Reduce manual paperwork and record-keeping.
- Improve the management of patient and doctor information.
- Design and implement a structured database.
- Provide an organized system for hospital operations.
- Apply software engineering concepts in a real-world project.

## 3. Main Project Modules

The project includes the following planned modules:

1. Patient Management
2. Doctor Management
3. Department Management
4. Appointment Management
5. Medicine Management
6. Prescription Management
7. Payment Management

## 8. Getting Started

Follow these steps to get a local copy of the project.

### Step 1: Clone the Repository

```bash
git clone https://github.com/HabibDev2003/Hospital_Management_System.git
```

### Step 2: Open the Project Folder

```bash
cd Hospital_Management_System
```

### Step 3: Open in Visual Studio Code

```bash

```

### Step 4: Switch to Your Assigned Branch

Frontend Developer:

```bash
git switch frontend
```

Backend Developer:

```bash

```

Database Developer:

```bash

```

## 9. GitHub Collaboration Workflow

All team members must follow the same GitHub workflow when working on the project.

### Upload Your Changes

After completing your work, run:

```bash
git add .
git commit -m "Describe your changes"
git push
```

### Create a Pull Request

1. Open the project repository on GitHub.
2. Select Pull Requests.
3. Click New Pull Request.
4. Select your working branch.
5. Select `main` as the base branch.
6. Create the Pull Request for review.

### Get the Latest Updates

To receive the latest approved project changes:

```bash
git switch main
git pull origin main
```

Then switch back to your assigned branch.

### Important Team Rules

- Do not work directly on the `main` branch.
- Each member must work on their assigned branch.
- Commit and push your work regularly.
- Create Pull Requests before merging into `main`.
- Do not overwrite another member's work.
- Use GitHub Issues to manage assigned tasks.
- Use GitHub Discussions for team announcements and general communication.
- Keep project documentation organized inside the `docs` folder.
